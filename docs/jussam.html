특강·발표용 테마. 처음 열면 검정 바탕(d 키로 밝게). 메시 그라디언트 표지, 파트별 시그니처 색, 둥근 카드(12px)와 그림자, 카드·스탯·차트 컴포넌트로 숫자가 많은 발표를 만든다. 목차 사이드바 · 원고 보기 · 확대/축소 · 넘침 표시 · 쪽 번호와 콜아웃·프롬프트·단계·타일 같은 기본 컴포넌트, 카드형·웹진형·인포그래픽 레이아웃도 함께 들어 있다.

# 분기 개발 생산성,<br>**숫자로 돌아보기**

배포 주기 · 리뷰 시간 · 장애 복구, 세 지표의 세 달

슬라이드는 항상 16:9(1280×720 캔버스)이고 창에 맞춰 비율대로 확대·축소된다. 컴포넌트 크기 값(px)은 이 캔버스 기준으로 적는다. 넘치는 내용은 스크롤 없이 잘리고 빨간 테두리와 넘친 길이가 표시된다(발표 화면만). 모든 슬라이드 오른쪽 아래에 쪽 번호(현재/전체), 맨 아래에 2px 진행 막대가 붙는다. 슬라이드 전환 효과(기본 slide-left)를 끄려면 헤드매터에 transition: none을 적는다.

사이드바와 조작

사이드바는 처음에 접힌 채 열린다. 왼쪽 위 ☰ 버튼이나 s 키로 펼치고, 오른쪽 가장자리를 끌어 폭을 바꾼다(더블클릭하면 기본 폭). 접힌 상태에서 ☰에 마우스를 올리면 애니메이션 · 테마 · 확대/축소 · 원고 버튼이 펼쳐진다. 조작 방식과 단축키는 hossam 테마와 같다.

키동작
s사이드바 접기/펼치기
a애니메이션 켬/끔(끄면 클릭 단계 없이 모두 보이고 슬라이드 단위로 넘어간다)
d밝은/어두운 테마
+ - 0본문 확대 · 축소 · 기본 배율

레이아웃

레이아웃쓰임프런트매터
cover표지·마무리·Q&A. 메시 그라디언트 배경, 위아래 머리말. 첫 표지(1쪽)에는 덱 헤더의 author가 제목 아래 붙는다eyebrow(위 작은 글, 생략하면 title의 · 앞부분), footer(아래 작은 글), mesh(soft 옅게 / none 없음), source(출처 각주)

default본문. 적지 않으면 이것. 내용은 세로 가운데eyebrow(제목 위 머리말, 파트 색), part(1~4 시그니처 색), source(아래 출처 각주 "출처 · …")

magazine왼쪽 큰 제목 + 리드문 + 본문, 오른쪽 ::right:: 칸-
infographic제목은 위, 나머지는 점 무늬 위 가운데 무대-

본문…

파트 색

part를 1~4로 주면 그 슬라이드의 강조색(제목 굵게, 머리말, 카드 윗선, 숫자, 세로선)이 함께 바뀐다. 파트 표지와 그 파트의 본문에 같은 번호를 쓰면 색으로 흐름이 이어진다.

part색예
1파랑 → 청록#007cf0 → #00dfd8
2보라 → 분홍#7928ca → #ff0080
3빨강 → 노랑#ff4d4d → #f9cb28
4파랑 → 분홍#007cf0 → #ff0080

글쓰기 규칙

  • # 제목(또는 ## 제목) 한 줄이 슬라이드 제목(44px)이고 사이드바 목차에 올라간다. ### 제목 슬라이드는 목차에서 한 단계 들여쓴다. 제목 안의 **굵게**는 파트 색 그라디언트가 된다. 표지에서는 전체 메시 그라디언트.
  • 제목 바로 아래 문단은 설명 줄(lead, 회색 20px)로 붙는다.
  • 문단·목록·표·코드·인용은 Slidev 마크다운 그대로. 목록 글머리는 짧은 가로선, 표는 얇은 가로줄에 첫 열은 굵게 한 줄로(첫 열이 표 폭의 30%를 넘으면 자동 줄바꿈, class: tbl-wrap · tbl-nowrap으로 강제), 코드는 어두운 상자.
  • 표지(cover)에서 ##는 44px, ###는 26px 회색 맺음말이고, ### 안의 **굵게**는 그라디언트.
  • 줄바꿈은 <br>. 숫자·단위·문장부호는 한국어 어절 중간에서 끊기지 않게(word-break: keep-all) 처리된다.

기본 컴포넌트

hossam 테마와 같은 이름 · 프롭의 기본 컴포넌트가 jussam 안에 따로 들어 있다. 모양은 jussam 바탕(둥근 모서리 · 검정 카드)을 따른다. 프롭은 각 파일 머리 주석에 있다.

컴포넌트쓰임
Callout · Prompt · Output상자. kind: eli5 · real · tip · warn · danger · ai · prompt · output · plain, 프롭 title · icon · color · n · tag · copy · cols. Prompt 글 안의 {치환 자리}는 노랑 굵게
Steps · Flow번호 목록(type: list · flow · timeline), color · start · vertical · center
Timelineevents를 주면 위의 날짜 축, 주지 않으면 <li>를 나열하는 Steps 타임라인
Statn을 주면 위의 큰 숫자 카드, value를 주면 숫자 타일(unit · label · color)
Tile · Core · Chip타일(kind plain · surface · soft · fill, tag · title · value), 핵심 한 줄(마지막 블록이면 맨 아래), 글 사이 작은 라벨
YoutubeCard유튜브 썸네일(누르면 재생, file:// 에서는 새 탭)

클래스도 같다: 형광펜 .hl(.ai .ok .warn .danger .ink), 빈칸 .blank(data-ph), .card(.py .ai .ok), .kicker, .tight · .flush, .labels, .fill-img, .comic, 슬라이드 프런트매터 class: dense · compact · tbl-wrap · tbl-nowrap.

주의할 점

  • 컴포넌트 안에 마크다운(굵게·목록·문단)을 쓰려면 여는 태그와 닫는 태그 앞뒤를 빈 줄로 띄운다. 빈 줄 없이 붙여 쓰면 글자 그대로 들어간다(<br>은 된다).
  • 긴 데이터는 프런트매터에. 태그를 여러 줄로 쪼개면 Slidev의 마크다운 파서가 문단으로 잡아 깨진다. Timeline·Bars처럼 배열이 길면 슬라이드 YAML에 두고 v-bind="$frontmatter.이름"으로 넘긴다.
  • **46%**가처럼 굵게 바로 뒤에 조사가 붙으면 닫히지 않는다(CommonMark 규칙: 닫는 ** 앞이 문장부호이고 뒤가 글자). 그런 곳만 <b>46%</b>가로 쓴다.
  • 한 줄로 쓴 컴포넌트(<Kicker>…</Kicker>)는 마크다운이 <p>로 감싸지만 테마가 그 영향을 되돌려 두었으니 신경 쓰지 않아도 된다.
  • 직접 HTML을 쓸 때 p1, h3, pt, ml 같은 짧은 클래스와 SVG의 font-size="11" 속성은 Slidev의 UnoCSS가 유틸리티로 해석해 크기를 바꾼다. 테마 클래스는 이미 피해 두었다.
